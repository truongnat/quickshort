Features

Everything the capture needs.

Annotations that stay editable

Pen, arrow, rect, ellipse, marker, text, pixelate. Shapes and text remain blocks — select, drag, delete. One key per tool, ⌘Z to undo.

P A R O M T X · TOOLS ON SINGLE KEYS
◎

Multi-monitor, native pixels

Drag across monitor boundaries. Per-monitor crops stitched at framebuffer resolution — Retina never downsampled.

⧉

Native OCR

Vision on macOS, WinRT on Windows, Tesseract on Linux. ⌘T puts the text on your clipboard.

● REC 15 FPS

Scrolling capture & recording

⌘G stitches scrolls into one tall image. ⌘R records the region to mp4 — slow encodes drop frames, never shorten the clip.

PIPEWIRE · SCREENKIT · GDI · PER-OS BACKENDS
⚲

Pin & beautify

Float a capture always-on-top as reference, or mount it on a soft gradient with rounded corners and shadow.

⎘

Share links

⌘L uploads WebP q95 to a Cloudflare Worker and copies an unguessable URL. Expires in 3 days, no account.

How it works

One hotkey, four beats.

1

⌘⇧S

Every monitor dims. Drag a region — across displays if you like.

2

Annotate

Draw on it first — blocks stay editable until you act.

3

Act

⌘S save · ⌘C copy · ⌘T OCR · ⌘L link · ⌘G scroll · ⌘R record.

4

Done

Action card confirms; capture lands in recents. Overlay exits clean.

Download

Install in one line.

macOS

DMG from releases, or the custom tap:

brew tap truongnat/tap brew install --cask quickshort

UNSIGNED BUILD · RIGHT-CLICK → OPEN ONCE

Linux · Windows

AppImage / .deb for Linux, NSIS installer for Windows — grab both from GitHub Releases. Optional: ffmpeg on PATH enables ⌘R recording.

sudo dpkg -i quickshort_amd64.deb # debian/ubuntu winget install ffmpeg # optional, windows
