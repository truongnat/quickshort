Privacy Policy

Last updated: 2026-01 · Tiếng Việt bên dưới

The short version

Quickshort runs entirely on your machine. Screenshots, annotations, OCR, and settings never leave your device. The only things that ever hit a server are: an image you explicitly share, an optional bug report you explicitly send, and an update check against GitHub Releases. There is no analytics, no tracking, no ads, and no account system.

What stays on your device

  • All captures and saved PNGs (~/Pictures/Quickshort or your configured directory)
  • Settings, hotkeys, and window preferences (~/.config/quickshort/)
  • OCR runs fully on-device — Apple Vision on macOS, Windows.Media.Ocr on Windows, Tesseract on Linux. No image or text is sent to a cloud OCR service.

What leaves your device — and only when you ask

1. Share link (opt-in, per capture)

Pressing Share uploads that one image — encoded as WebP — to a Cloudflare Worker (quickshort-share), which stores it in Cloudflare Workers KV and returns a random 128-bit URL (/s/<id>.webp). Anyone holding the link can view the image until it expires.

DataWhereRetention
Shared imageCloudflare KVAuto-deleted after 3 days
Uploader IP (rate-limit key rl:<ip>:<date>)Cloudflare KVAuto-deleted after 2 days
Local archive copy (shared/ subfolder)Your diskUntil you delete it

Limits: 12 MB per upload, 30 shares per IP per day. Shared images are not indexed or listed; the unguessable ID is the only protection, so share links are for public-or-semi-private content — not for secrets.

2. Bug report (opt-in)

The in-app report form sends your app version, OS/arch, a diagnostics bundle, and your optional note to the quickshort-report Worker, which files it as a public GitHub issue on truongnat/quickshort. The issue is publicly visible and effectively permanent — do not paste secrets, tokens, or private screenshots into the note.

3. Update check (automatic)

At most once a day the app queries api.github.com/repos/truongnat/quickshort/releases/latest to compare versions. GitHub sees the request's IP and user-agent. No identification is sent. Turn it off with auto_update = false in config.toml.

Third parties

  • Cloudflare — hosts the share/report workers and KV storage; standard edge request logs apply (Cloudflare's privacy policy governs their side).
  • GitHub — release downloads, update checks, public issue reports, and this documentation site (GitHub Pages).
  • Google Fonts — this website loads font files from fonts.googleapis.com; the app itself loads no remote resources.

What we don't do

  • No analytics, telemetry, or crash reporting without an explicit click
  • No accounts, no sign-in, no email collection
  • No persistent storage of your images beyond the 3-day share TTL
  • No sale or sharing of any data with anyone

Your controls

  • Nothing is uploaded unless you press Share or send a bug report.
  • Shared links expire automatically; deleting the local file does not affect the link and vice versa.
  • To remove a public bug report or a shared image early, open an issue on GitHub and it will be deleted.

Chính sách bảo mật (Tiếng Việt)

Quickshort chạy hoàn toàn trên máy của bạn. Ảnh chụp, chú thích, OCR và cấu hình không bao giờ rời thiết bị. Chỉ có ba thứ chạm tới server: ảnh bạn chủ động bấm Share, báo lỗi bạn chủ động gửi, và request kiểm tra cập nhật tới GitHub Releases. Không analytics, không tracking, không quảng cáo, không tài khoản.

  • Share: ảnh (WebP) lên Cloudflare Worker, lưu trong Workers KV, tự xoá sau 3 ngày. Link là ID ngẫu nhiên 128-bit — ai có link đều xem được, nên đừng dùng cho nội dung bí mật. IP của bạn được lưu trong khoá rate-limit 2 ngày (chặn 30 share/ngày/IP).
  • Báo lỗi: version, OS, diagnostics và ghi chú của bạn được đăng thành GitHub issue công khai — đừng dán mật khẩu/token vào.
  • Update check: gọi GitHub Releases API; GitHub thấy IP của bạn. Tắt bằng auto_update = false trong config.toml.
  • OCR: chạy on-device (Vision / Windows.Media.Ocr / Tesseract), không gửi ảnh hay text đi đâu.
